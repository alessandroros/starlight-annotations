Notes can have a kind (question, problem, proposal or decision), shown as a label and filtered on the overview page. **+ Note on this page** writes a note about the whole page rather than a passage. In the file, a thread has an optional `kind`, and a page note has a `target` without a `selector`. Slack and Teams titles name the kind ("Ada added a question on …").
