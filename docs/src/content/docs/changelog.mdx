starlight-annotations follows [semantic versioning](https://semver.org). While it is in `0.x`, a minor version (`0.2.0` → `0.3.0`) may change behavior or options; the notes below say what to update. Patch versions only fix things.

Every version is on [npm](https://www.npmjs.com/package/starlight-annotations?activeTab=versions) and has a [GitHub release](https://github.com/alessandroros/starlight-annotations/releases). To hear about new ones, watch the repository and choose **Custom → Releases**.
